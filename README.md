# Часы для экрана пассажира Lixiang

Приложение показывает два циферблата на весь экран: «Классика» (стрелочный циферблат с панелями недели, солнца и луны) и «Минимализм» (крупные цифры).

Что умеет:
- Работает без интернета. Восход, закат и фаза луны считаются по координатам машины.
- Пять тем: Авто (днём Графит, после заката Ночь), Графит, Ночь, Бордо, Светлая.
- Позволяет выбрать часовой пояс, если в машине стоит пекинское время.
- Не даёт экрану гаснуть, скрывает системные панели.
- Касание экрана открывает меню, повторное касание или 5 секунд без действий закрывают его.
- Запоминает выбор после перезапуска.

## Как собрать APK

### Вариант 1. GitHub (без установки программ)
1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository).
2. Нажмите «uploading an existing file» и перетащите туда всё содержимое этой папки, включая скрытую папку `.github`.
3. Откройте вкладку **Actions**. Сборка «Собрать APK» запустится сама и займёт 3–5 минут.
4. Откройте завершённую сборку и внизу в разделе **Artifacts** скачайте `LiClock-apk` (это zip, внутри лежит `app-release.apk`).

### Вариант 2. Android Studio
Откройте папку как проект (File → Open), дождитесь синхронизации и выберите Build → Build APK(s).

## Как поставить в машину
- **Через флешку или магазин.** Если в машине стоит CarModApps, LiNEO или LiApp Store, установите APK через их функцию «установка с флешки».
- **Через ADB** (ноутбук подключён к машине):
  `adb install -r app-release.apk`
  Чтобы приложение появилось на пассажирском экране, его обычно нужно сначала поставить на центральный экран, а потом на пассажирский. Так устроены магазины для Lixiang.
- При первом запуске разрешите доступ к местоположению. Без него часы покажут восход и закат для Москвы.

## Устройство проекта
- `app/src/main/assets/clock.html` — весь интерфейс часов (HTML + SVG). Его можно открыть в браузере на компьютере и посмотреть.
- `app/src/main/java/.../MainActivity.java` — полноэкранное окно и передача координат.
- Шрифт Manrope, лицензия SIL OFL (`assets/manrope-OFL.txt`).
