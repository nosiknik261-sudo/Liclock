# Политика конфиденциальности приложения «Часы для Lixiang»

Дата вступления в силу: 2 ноября 2026 года.

Разработчик: Носик Николай (далее «разработчик»).
Связь с разработчиком: через страницу приложения в RuStore или раздел Issues: https://github.com/nosiknik261-sudo/Liclock/issues

## Какие данные использует приложение

**Местоположение (примерное или точное).** Координаты нужны только для того, чтобы посчитать время восхода и заката солнца и показать название города. Расчёт выполняется прямо на устройстве. Координаты и город сохраняются только в памяти приложения на этом устройстве, чтобы не запрашивать их при каждом запуске.

Если системная служба определения адреса устройства (Geocoder) доступна, для получения названия города координаты могут передаваться ей. Этой службой управляет производитель устройства, а не разработчик.

**Настройки** (выбранный циферблат, тема, часовой пояс) хранятся только на устройстве.

## Что приложение НЕ делает

- Не собирает и не передаёт разработчику никаких персональных данных.
- Не содержит рекламы, аналитики и сторонних SDK для отслеживания.
- Не требует регистрации и не использует аккаунты.
- Не обращается к интернету само по себе: все расчёты выполняются локально.

## Разрешения

- `ACCESS_COARSE_LOCATION` и `ACCESS_FINE_LOCATION` нужны для расчёта восхода и заката. Без них приложение работает и показывает данные для Москвы.

## Удаление данных

Все данные хранятся только на устройстве и удаляются вместе с приложением или при очистке его данных в настройках системы.

## Изменения политики

Если политика изменится, новая версия будет опубликована по этому же адресу.
